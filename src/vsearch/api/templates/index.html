vsearch Demo

vsearch is an in-memory vector database built from scratch with an HNSW index, C++/AVX2 distance acceleration, and hybrid filtered search. This interactive demo explores 20,000 synthetic 64-dimensional vectors clustered across consumer categories.

Note: The demonstration index contains 20,000 synthetic 64-d vectors with single-process ACID durability.
