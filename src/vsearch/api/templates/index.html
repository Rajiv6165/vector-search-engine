How it works

A high-performance HNSW vector search pipeline designed from first principles.

1. Turn items into numbers (vectors)

Embeddings represent semantic properties as high-dimensional coordinates, placing similar concepts close together in metric space.

2. Index them in a layered graph (HNSW)

Upper graph layers act as long-range express highways for rapid navigation; lower layers provide fine-grained nearest neighbor connections.

3. Jump to the closest ones instead of checking everything

Greedy beam search navigates directly to the target neighborhood in logarithmic steps, avoiding exhaustive scans across millions of items.
